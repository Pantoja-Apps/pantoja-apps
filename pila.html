Arquitectura & Gestión de Estado

Patrones orientados a separación de incumbencias y flujos unidireccionales de datos (UDF).

  • Clean Architecture: Capas totalmente desacopladas (Domain, Data, Presentation).
  • Dagger Hilt & Koin: Inyección de dependencias modular y orientada a pruebas.
  • Coroutines & Flow: Programación asíncrona avanzada y reactiva en ViewModel.
  • StateFlow & SharedFlow: Emisión segura de estados inmutables hacia la UI en Compose.

Testing & Calidad de Software

Garantía de calidad mediante pruebas automatizadas en cada ciclo de integración continua.

  • JUnit 5 & MockK: Pruebas unitarias de repositorios, casos de uso y ViewModels.
  • Turbine: Librería especializada para testear Kotlin Flows de manera reactiva.
  • Compose UI Test: Pruebas de instrumentación y Golden Tests visuales.
  • SonarQube & Detekt: Análisis estático para detección de deuda técnica y olores de código.

Desglose de Código Avanzado (Kotlin Flow Repository Pattern)

Ejemplo limpio de gestión reactiva de datos con inyección Hilt y despacho en hilos de I/O.

class MediaRepository @Inject constructor(

private val api: MediaApiService,

private val dao: MediaDao

) {

val streams: Flow<List<StreamModel>> = dao.observeStreams()

.flowOn(Dispatchers.IO)

.conflate()

}
